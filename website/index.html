Features

Everything you need, nothing you don't.

A focused utility that answers one question well — how much Claude Code usage do I have left — and stays out of the way the rest of the time.

Usage at a glance

Check your remaining Claude Code usage without constantly opening another application.

Tray / menu bar

Keep the app out of the way until you actually need it — a click away in the system tray or menu bar.

Prompt Calculator

Estimate whether a task is likely to fit within your remaining usage — as a range, with a confidence level.

Lightweight

Designed to stay idle and consume minimal resources — built on a native WebView, not a bundled browser.

Privacy-focused

Keeps the experience local and avoids unnecessary data collection. No account, no tracking.

Cross-platform

Available for Windows and macOS, with native conventions on each — one focused tool, two platforms.

Prompt Calculator

Will your task fit?

Before you start a big task, the Prompt Calculator estimates how likely it is to finish before you run out of usage. It weighs a few signals and returns an honest range — never a fake exact number.

  1. 1Remaining usage
  2. 2Task complexity
  3. 3Model
  4. 4Estimated usage
  5. 5Confidence

Estimates are approximate and not guaranteed. Real consumption depends on message count, context size, tools used and iterations — none knowable in advance.

Builds aren't notarized, so Windows SmartScreen or macOS Gatekeeper may prompt on first launch.

macOS: if it says the app “is damaged”, that's just Gatekeeper on a non-notarized download — clear the quarantine flag once:
xattr -dr com.apple.quarantine "/Applications/Claude Usage Tray.app"
then open it normally. Full install notes.

Privacy

No account. No tracking. No unnecessary data collection.

The app reads your existing Claude Code session locally and only makes the same usage request Claude Code itself makes — with your own local token, when you ask it to. Your prompts stay on your machine.

✓ Reads your local session read-only — it never creates its own credential store.
✓ The Prompt Calculator runs entirely on your device.
✓ No cookies, no analytics, no scraping — this website included.
